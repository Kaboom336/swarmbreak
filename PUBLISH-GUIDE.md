# Publish guide: what Zion clicks

Everything else (code, Rojo, tests, IDs paste) is done by Claude. These steps need your account.

## A. One-time setup (about 15 minutes)
1. Install Roblox Studio: https://create.roblox.com/ > "Start Creating". Sign in with your Roblox account.
2. Tell Claude "Studio is installed". Claude installs Rojo and the Rojo plugin, syncs the game, and playtests.

## B. First publish (makes the game exist on Roblox)
1. In Studio, with the game open: File > Publish to Roblox.
2. Name: Swarm Break. Description: paste from the "Store text" section below. Genre: Action. Devices: all four.
3. Click Create. Leave it Private for now.
4. Game Settings (Home > Game Settings) > Security > turn on "Enable Studio Access to API Services" > Save.
   (Lets the leaderboard save best waves while testing.)
5. Tell Claude "published".

## C. Game passes and coin packs (about 10 minutes)
Follow MONETIZATION-SETUP.md. You create them, paste the IDs into the thread, Claude puts them in the code.

## D. Go public
1. Playtest once yourself (Claude will say when it's ready).
2. Creator Dashboard: https://create.roblox.com/dashboard/creations > Swarm Break > Access > Public > Save.
3. Tell Claude "it's public". Clipper then posts gameplay clips on PrankStar TikTok with the game link.
