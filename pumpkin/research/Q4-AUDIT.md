# Q4-AUDIT: Pumpkin game-feel and quality audit

Audited 2026-10-05 against the entire `pumpkin/` Rojo project, its tests, the shipped captures in `pumpkin/art/`, and [Q4-REFERENCES.md](Q4-REFERENCES.md). The audit is a pre-change diagnosis: it does not claim that an old capture overrides newer source configuration. In particular, the night screenshots show the shipped presentation that prompted the playtest, while `default.project.json` now specifies daytime lighting.

Reference shorthand used below:

- **Stone** — +1 Stone Skipping: immediate `+1` event feedback and an obvious progression chain ([Roblox](https://www.roblox.com/games/111543903102439/1-Stone-Skipping), [gameplay guide](https://stoneskipping.wiki/)).
- **Egg** — Break and Steal an Egg: commit → danger → return → bank loop, bright result presentation ([Roblox](https://www.roblox.com/games/114326934417838/Break-and-Steal-an-Egg), [gameplay video](https://www.youtube.com/watch?v=uT5R6PyMrQg)).
- **Fat Roll** — Get Fat And Roll Race: visible body-scale progression and downhill payoff ([Roblox](https://www.roblox.com/games/14494334042/Get-Fat-And-Roll-Race), [gameplay video](https://www.youtube.com/watch?v=4-jSDYpBANo)).
- **Box** — Ride a Box Down a Slide: readable contained rider, ramps, rocks, balance, and speed ([Roblox variant](https://www.roblox.com/games/14777367640/Ride-A-Box-Down-A-Slide), [gameplay video](https://www.youtube.com/watch?v=pm0uwYs2Nzw)).
- **Marble** — Mega Marble Run Pit: avatar inside the marble; steep drops, funnels, walls, curved guards, and a tunnel ([Fandom course notes](https://roblox.fandom.com/wiki/Player:SeanMichaell/Mega_Marble_Run_Pit), [gameplay video](https://www.youtube.com/watch?v=Z6PBkz9gq6c)).
- **Roblox guidance** — the platform targets 60 FPS (16.67 ms/frame), recommends a real low-end baseline device and streaming for larger places, and advises contextual, visual onboarding with delayed hints ([performance](https://create.roblox.com/docs/performance-optimization), [design for performance](https://create.roblox.com/docs/performance-optimization/design), [onboarding techniques](https://create.roblox.com/docs/production/game-design/onboarding-techniques)).

Severity means: **P1** blocks the core fantasy, comprehension, or a fair playable run; **P2** materially weakens quality, retention, or accessibility; **P3** is polish. Each row has exactly one implementation owner. Q4-E owns every important item outside the narrower A–D briefs.
