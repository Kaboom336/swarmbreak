# GOOD-GAME-STUDY: what Pumpkin must look, play, and feel like

Research date: **2026-10-05**. This is web research only. It makes no claim that a public video exposes a game's private source, asset licenses, exact camera constants, or production pipeline. `Observed` means visible in a linked listing/video; `verified` means stated by the creator, Roblox, or a dated guide/wiki. Prices are dated snapshots because Roblox supports regional/personalized pricing; the purchase prompt is authoritative.

## Executive verdict

Pumpkin's problem is not a missing feature. It is that the fantasy is still read through systems instead of through the object. A good version can be understood with the HUD hidden:

1. I make a pumpkin large and valuable.
2. I climb inside it and commit to a downhill run.
3. It rolls, leans, hits, sheds pieces, and visibly approaches failure.
4. It ruptures into goo, seeds, and a reward.
5. The reward remains meaningful in the plaza as an upgrade, pet, collection, or unlocked route.

The current market rewards extremely plain verbs, enormous recognizable objects, state changes that can be read from across a phone screen, and a reward every few seconds. The opportunity is to combine that clarity with a short run that is genuinely fun to control. Pumpkin should borrow the market's legibility, not its clutter or coercive monetization.

## 1. Steal An Egg — the clearest current object-state loop

Sources: [Roblox listing](https://www.roblox.com/games/107778070777162/Steal-An-Egg), [August 2026 beginner route](https://steal-an-egg.robloxgamewiki.com/guide/beginner-guide/), [September 2026 gameplay video](https://www.youtube.com/watch?v=6PKdd9pXlyM), [dated pass prices](https://steal-an-egg-3ny.wiki/wiki/gamepasses/).

- **Art, lighting, VFX:** Oversized eggs and pets carry the scene. Biomes use broad, toy-like colour blocks and large landmarks rather than surface detail. Valuable states change silhouette, size, rarity colour, and mutation treatment. The hatch is a natural anticipation-contact-reveal effect.
- **UI, animation, camera:** Third-person camera keeps the carried egg and return route readable. Large overhead labels and timers attach information to the object. Carrying a heavier egg changes movement, while guardian pursuit and knock-loose reactions animate risk. UI supports the object instead of replacing it.
- **Movement feel:** The important change is load: carrying slows the avatar, so the same route becomes tense on the way home. A hit can knock the egg loose. This creates a readable commit/escape arc without advanced controls.
- **Core loop:** Steal egg → escape → hatch at base → pet earns money → upgrade treadmill/base and speed → steal rarer eggs. Offline hatching makes the object continue changing while the player is away.
- **Monetization:** A September 2026 public snapshot reported `2x Money` at **399 Robux** and `2x Growth Speed` at **467 Robux**, with lower personalized prices possible. These are strong accelerators, not cosmetics; Pumpkin should not copy their pressure.
- **Copy exactly:** Give the hero object a visible state journey and make commitment change how movement feels. The Pumpkin equivalent is healthy shell → warning cracks → sag/chunk loss → burst → revealed payout. Put status on/near the pumpkin, not in another corner panel.

## 2. +1 Speed Keyboard Escape — immediate motion-to-number feedback

Sources: [Roblox listing](https://www.roblox.com/games/81245647985532/1-Speed-Keyboard-Escape), [May 2026 gameplay video](https://www.youtube.com/watch?v=02Ja8YU9bms), [July 2026 gameplay video](https://www.youtube.com/watch?v=I12L26L6-Mo), [dated API-based price study](https://earnaldo.com/blog/speed-keyboard-escape-tier-list-2026).

- **Art, lighting, VFX:** Giant keyboard keys turn one familiar object into the whole course. Candy/chocolate variants use glossy large forms, bright sky lighting, strong colour zoning, trails, and auras. The world is visually simple enough that the next foothold reads instantly.
- **UI, animation, camera:** Large Speed/Wins/Rebirth readouts, direct `+1` feedback, and obvious finish/reward surfaces. The standard chase camera lets the avatar and upcoming keys fill the frame. Running, jumping, falling, and trail motion do most of the animation work.
- **Movement feel:** Every step raises Speed, so motion itself is progression. Increasing velocity makes familiar jumps newly risky; falling resets position. The official description explicitly sells smooth movement, keyboard clicks, and ASMR feedback.
- **Core loop:** Walk/train → gain Speed every step → attempt keyboard obby → earn Wins → buy multipliers/rebirth → cross harder stages.
- **Monetization:** An August 26, 2026 API snapshot reported `2x Wins` **95 Robux**, Gold/Diamond/Candy/Admin treadmills **69/299/749/1,599 Robux**, trails **19–2,399**, and auras **75–1,849**. A September repricing later put Gold at **79**, Diamond **345**, Candy **749**, Admin **1,199** ([updated price study](https://earnaldo.com/blog/speed-keyboard-escape-free-robux-guide)). This volatility is exactly why Pumpkin must display live prices.
- **Copy exactly:** One motion event, one immediate response. Each clean steer/contact in Pumpkin should yield a sound plus world-space response within one rendered frame. Also copy the single-prop visual premise: the course must be unmistakably “pumpkin downhill,” not a generic obby with orange paint.

## 3. Fish It! — short active input wrapped in huge collection depth

Sources: [Roblox listing](https://www.roblox.com/games/121864768012064/Fish-It), [viral gameplay video](https://www.youtube.com/watch?v=3Q7L_9cq4yg), [mechanics guide](https://fishit.gg/mechanics), [current overview](https://fishit.gg/overview), [2026 pass guide](https://rbblox.com/en/blog/fish-it-gamepasses-guide).

- **Art, lighting, VFX:** Bright open water, themed islands, readable rods/boats, and enormous rare fish. Mutations such as Gold, Neon, Negative, and Rainbow change the collectible's presentation and sale value. Water/sky provide quiet background space for catch effects.
- **UI, animation, camera:** Charge and rapid-click prompts are short and central; rarity/name/weight make a catch understandable. The camera stays conventional until a catch gives it a reveal subject. Rod bend, line motion, fish pull, catch lift, and reveal pose provide the animation arc.
- **Movement feel:** Sailing/exploration is relaxed; fishing compresses input into charge → rapid reel. That contrast keeps the core action active without making the whole session exhausting.
- **Core loop:** Charge cast → reel → reveal fish/rarity/mutation → sell → upgrade rod/luck/speed/weight → sail to new islands and complete collections. The official description advertises over one million variations.
- **Monetization:** The game sells passes such as auto-cast, luck, sell-anywhere, XP, and boat/skin bundles, but the reviewed sources did not provide a complete trustworthy October price table. Treat any price outside the live prompt as **UNKNOWN**.
- **Copy exactly:** Let the run stay active and short, then slow down for the object/result reveal. Pumpkin's post-explosion reward needs a named rarity/state and a clean pedestal moment, not coins sprayed while the camera snaps away.

## 4. Fisch — atmosphere and tactile minigame over simulator chrome

Sources: [official/community wiki](https://fisch.wiki/), [Roblox/Fandom overview](https://roblox.fandom.com/wiki/Fisching/Fisch), [current currency explanation](https://fisch.wiki/wiki/c-currency/), [gamepass list](https://fisch.fandom.com/wiki/Gamepasses), [DevForum launch thread linked by the wiki](https://devforum.roblox.com/t/new-roblox-fishing-game-fisch/3183374).

- **Art, lighting, VFX:** More restrained and atmospheric than the average simulator: water, fog, weather, day/night, island silhouettes, bobber splashes, fish glints, and event colour shifts. Rare catches are special because the ordinary world is not permanently neon.
- **UI, animation, camera:** The fishing bar is the focus only during the minigame; the rest of the screen leaves room for exploration. Standard third-person framing supports boats and islands. Cast, bobber, tension, reel, fish hold, and appraisal form a readable animation chain.
- **Movement feel:** Walking and boating are deliberately slower than the skill interaction. The reel minigame supplies tension through a moving target/progress relationship rather than raw clicking alone.
- **Core loop:** Explore → choose location/weather/bait → cast and control reel → sell/appraise/collect → buy rods/boats → reach rarer fish, mutations, and events.
- **Monetization:** Dated public prices include `Bobber Pack` **99 Robux**, `Double XP` **199**, `Supporter` **229**, `Sell Anywhere` **399**, and `Appraiser's Luck` **399** ([price list](https://sites.google.com/view/fisch-wiki/gamepasses)). The Fandom list notes live discounts can differ.
- **Copy exactly:** Reserve high saturation and glow for value/state changes. Give the normal pumpkin warm material richness, then let cracks, inner goo, and reward rarity introduce the brightest colours. Pumpkin should have an audible/visual “tension” build before failure, like a line about to break.

## 5. Break and Steal an Egg — four clean beats in one trip

Sources: [Roblox listing](https://www.roblox.com/games/114326934417838/Break-and-Steal-an-Egg), [gameplay video](https://www.youtube.com/watch?v=uT5R6PyMrQg), [current beginner guide](https://break-and-steal-an-egg-roblox.wiki/), [current chart record](https://www.rotrends.com/game/10765288803/Break-and-Steal-an-Egg).

- **Art, lighting, VFX:** Giant bright eggs and animals dominate bases and guarded areas. Break effects, crack progression, hatch reveals, rarity colour, and cash feedback make one target produce multiple visual payoffs.
- **UI, animation, camera:** Third-person camera keeps target, pursuers, and base landmark visible. Overhead prompts and large cash feedback are direct. Pickaxe swings, egg damage, hatch, pickup/carry, guard chase, and base placement create different silhouettes.
- **Movement feel:** The outgoing trip is preparation; danger begins after taking the result. Route choice and return speed matter more than complex buttons.
- **Core loop:** Break egg → hatch animal → steal/carry → escape guards → place in base → earn cash → upgrade speed, pickaxe, and satchel → fill index.
- **Monetization:** No reliable complete current price list was found in the reviewed official/wiki/video sources. Price is **UNKNOWN** until queried live.
- **Copy exactly:** Split one run into named beats that look different: latch, roll, warning, breakup, burst, bank. The egg demonstrates that cracks should be progressive information, not decoration added only on the last frame.

## 6. +1 Stone Skipping — the best micro-feedback reference

Sources: [Roblox listing](https://www.roblox.com/games/111543903102439/1-Stone-Skipping), [dated gameplay wiki](https://stoneskipping.wiki/), [second gameplay guide](https://stoneskippingguide.wiki/), [October 2026 update record](https://rouniverse.com/articles/1-stone-skipping-updates/).

- **Art, lighting, VFX:** Saturated themed water lanes and large novelty throwables. Splash/bounce positions form a clean line through uncluttered space; sequential biomes change palette and landmark language.
- **UI, animation, camera:** Huge Skill/Wins/level progress and a `+1` on every bounce. Throw wind-up, release, bounce rhythm, and distance result do the animation work. Public sources do not verify a special projectile camera, so that should not be copied as fact.
- **Movement feel:** It converts a single throw into repeated rhythmic contacts. Each bounce is both physics and progress, producing a cadence players can hear and count.
- **Core loop:** Gain/throw → each bounce adds Skill → farther zones award Wins → buy throwables/pets/levels → rebirth for a multiplier.
- **Monetization:** The reviewed sources verify pets, throwables, and rebirth progression but not a trustworthy current Robux price table. Price is **UNKNOWN**.
- **Copy exactly:** Make every ground revolution/contact phase legible through a restrained roll loop, dust pulse, and pitch rhythm. During deterioration, each new crack/chunk event should be countable just as each bounce is countable.

## 7. Grow a Garden — retained objects and visible mutation

Sources: [Roblox listing](https://www.roblox.com/games/126884695634066/Grow-a-Garden), [Roblox interview with creator Jandel](https://about.roblox.com/en-nz/newsroom/2025/09/roblox-tech-talks-episode-29-creator), [December 2025 gameplay](https://www.youtube.com/watch?v=38P9CZ3givU), [AP creator/business report](https://apnews.com/article/2f5e4368448d57002d08b1b3d4a289ca), [dated event price](https://www.pcgamer.com/games/survival-crafting/grow-a-garden-hinomai-seeds/).

- **Art, lighting, VFX:** A bright fenced toy garden with oversized crops. Growth, scale, mutation colour, weather, and pet activity make value remain visible in the world. Ordinary soil/fences are quiet; giant or mutated crops become spectacle.
- **UI, animation, camera:** Conventional third-person camera and compact shop/inventory flows keep the garden itself central. Planting, sprouting, multi-stage growth, harvest, mutation aura, and scale reveal are the animation system.
- **Movement feel:** Low stress and low precision. Satisfaction comes from short routes among persistent objects and from returning to visible change, including offline growth.
- **Core loop:** Buy seed from rotating stock → plant → wait/return → harvest/sell/keep → reinvest in rarer seeds, pets, gear, and mutations → display increasingly absurd garden results.
- **Monetization:** A July 2025 `Exotic Zen Seed Pack` was **199 Robux**. Public reporting also documents paid acceleration/stealing, while the audit's prior source records the Forever Pack escalating from **39 to 1,199 Robux**. These are dated and aggressive; copy neither randomness nor escalating pressure.

## 9. Steal a Brainrot — instantly recognizable collectibles and social risk

- **Copy exactly:** One glance must reveal which pumpkin state/reward is ordinary, rare, or extraordinary. Give each deterioration/reward tier a different silhouette or material event, not just a different floating adjective.

## Cross-game design rules for Pumpkin

1. **One giant noun beats a detailed room.** Egg, keyboard, fish, crop, and meme character are readable at thumbnail scale. The pumpkin must own at least one-third of the active-frame height during the run and be the brightest warm object in the scene.
2. **Value is physical.** Scale, mutation, cracks, carried weight, placed collectibles, and course length all show progression without opening a menu.
3. **Every useful input has a cadence.** Step clicks, stone bounces, pickaxe hits, reel ticks, and cash pulses answer immediately. Pumpkin needs roll rumble, steering scrub, pickup pop, crack ticks, chunk thuds, and the burst.
4. **A run has contrasting states.** Calm/steal/escape; cast/reel/reveal; build/play/collect. Pumpkin needs ready/roll/deteriorate/explode/reveal/return.
5. **The reward gets a pause.** Rare fish, pets, mutations, and eggs are staged as subjects. Do not let the explosion and reward text compete in the same 300 ms.
6. **Good bright art still has hierarchy.** Fisch and Grow a Garden show why ordinary scenery must be quieter than state changes. Saturating everything produces no focal point.
7. **Current hits are not automatically ethical templates.** Avoid paid random packs, theft prompts, opaque escalating tracks, fake urgency, and extreme pay-to-skip. Pumpkin's paid offers should follow a fun free loop.

## How the assets are probably made—and what Pumpkin should do

### What can and cannot be known from the web

Public gameplay shows final assets, not source provenance. Unless a creator says otherwise, it is not responsible to claim that a specific top game used a particular kit, AI generator, contractor, or Blender file. The robust production pattern is mixed: primitive/code-built layout for iteration, custom meshes for hero silhouettes, reusable purchased/free packs for secondary environment dressing, and Roblox-native particles/UI/lighting for feedback. Roblox officially distinguishes Studio parts from custom meshes made in Blender/Maya and imported as MeshParts ([3D art and Studio](https://create.roblox.com/docs/art/overview-studio), [custom 3D assets](https://create.roblox.com/docs/art/modeling)). Roblox's Blender plugin can transfer objects directly, while `.gltf`, `.fbx`, and `.obj` remain supported workflows ([Blender plugin](https://create.roblox.com/docs/art/modeling/roblox-blender-plugin), [Blender import/export guide](https://create.roblox.com/docs/art/blender)).

### Recommended Pumpkin split

- **Custom Blender meshes (the 20% players stare at):** one definitive pumpkin shell with 8–12 deep ribs; separate inner goo membrane; stem; face; three crack overlays/mesh states; 6–10 detachable rind chunks; seed and pulp meshes; rider window/interior; hero eggs/pets; finish/reward pedestal. These assets establish identity and must not be generic store models.
- **Curated kit assets (roughly 50% of visible environment instances, but fewer unique assets):** graves, fences, lamps, rocks, dead trees, candy, coffins, arches. Recolour/recompose them into one palette; do not scatter packs unchanged.
- **Studio/code-built modular geometry (the structural 30%):** collision-safe track spline segments, banks, rails, tunnel shells, invisible hit volumes, spawn pads, lane markers, camera blockers, guide ribbons, and LOD/effect controls. Use simple parts for structure because they are fast to tune and reliable for physics.
- **Roblox-native presentation:** ParticleEmitters, Trails, Beams, Highlights, Bloom/ColorCorrection, UI, sound groups, camera/FOV, and local-only debris. Roblox notes that clients can create visuals when the server only needs outcome/location, and warns that particle changes/object density can be expensive ([performance guidance](https://create.roblox.com/docs/performance-optimization/improve)).

### Free/cheap candidates to evaluate—no purchase required

1. **[KayKit Halloween Bits](https://kaylousberg.itch.io/halloween-bits)** — free tier has 60+ mobile-oriented low-poly graveyard models, one atlas texture, FBX/OBJ/glTF, CC0. The optional Extra tier is **$3.95** and source `.blend` tier **$5.95**, but Pumpkin does not need to buy them for a prototype.
2. **[Kenney Graveyard Kit](https://opengameart.org/content/graveyard-kit)** — 90 optimized CC0 models including graves, coffins, fences, benches, and characters; useful as the neutral quality/reference bar.
3. **[KayKit Spooktober Seasonal Pack](https://opengameart.org/content/kaykit-spooktober-seasonal-pack-11)** — CC0 floor tiles, characters, dead trees, candy, containers, graveyard assets, and pumpkins. Use candy/containers selectively; do not use its pumpkin as the hero.
4. **[The Obby Kit — Creator Store](https://create.roblox.com/store/asset/7486694215/The-Obby-Kit)** — free model with 121 MeshParts and 75,053 triangles. Treat it as a mechanics/prototyping source only; it is too generic and heavy to become Pumpkin's visual identity.
5. **[Low Poly Horror Pack — Creator Store](https://create.roblox.com/store/asset/4994143684)** — seven MeshParts/8,469 triangles. Evaluate individual silhouettes only after script/remotes inspection.
6. **[Medieval Low Poly Kit — Creator Store](https://create.roblox.com/store/asset/15239103896/Medieval-Low-Poly-Kit)** — broad free nature/rock/building source, but 163 MeshParts and 140,927 triangles; harvest a few pieces, never insert the whole pack into the shipping place.

Roblox says the Creator Store includes models, meshes, audio, plugins, UI, and scripts from Roblox and independent creators ([Creator Store documentation](https://create.roblox.com/docs/production/creator-store)). That convenience is also the risk. For every imported model: insert into an empty quarantine place, unpack packages, reject every Script/LocalScript/ModuleScript/RemoteEvent/RemoteFunction/PackageLink, record creator URL/license/date, normalize pivot/scale/collision/material, and re-export only the approved art. Never build gameplay on a kit's embedded scripts.

### Asset decision for Pumpkin

Use **KayKit/ Kenney as a temporary environment vocabulary and a measured quality bar**, custom-model the pumpkin and reward objects in Blender, and keep the track collision/code-built. This is faster than custom-modelling every tombstone, safer than shipping a full Creator Store map, and visually stronger than constructing the hero from spheres and wedges. Reimport custom assets as named pieces so crack states and chunks can be revised without breaking runtime references; Roblox's reimport system preserves Roblox properties when mesh paths/names stay stable ([reimport documentation](https://create.roblox.com/docs/art/modeling/reimport)).

## Zion's mechanic: roll → deteriorate → explode → reveal

The pumpkin is a temporary vehicle and a visible health/timer. “Runs out” should mean its stored Size/energy has been converted into distance and reward, not that the player suddenly dies. Deterioration begins while steering still matters, then control cleanly ends before the explosion.

### Full run rhythm

| Stage | Run time / duration | Visual state | Control/camera | VFX and sound |
|---|---:|---|---|---|
| 0. Latch | 0.00–0.45 s | Rider drops inside; two shell halves squeeze/settle; face lights | Camera eases to chase; input shown but launch lane is safe | Wooden latch, soft hollow `thump`, stem bob; no shake |
| 1. Fresh roll | 0.45 s to last 25% of energy | Saturated orange shell, clean ribs, firm round silhouette | Full steering; 65 → 145 studs/s target; speed FOV follows measured velocity | Low roll rumble, contact ticks, dust/leaf ribbon; pitch rises with speed |
| 2. Warning | Last 25% or about 1.2–1.8 s before stop | Face flickers; first hairline cracks glow dull yellow-green; orange shifts 10–15% toward brown | Steering remains full; camera moves 5–8% closer so damage reads | Two dry creaks 250–400 ms apart; low heartbeat/sub hit; HUD says `SHELL FAILING` once, not continuously |
| 3. Crack | 0.00–0.30 s after energy reaches zero | Three major cracks propagate from contact side; squash to 0.94Y/1.03XZ | Steering disabled; preserve forward coast; 0.04 s hit-stop at the main crack | One-frame warm inner flash; 6–10 tiny rind chips; sharp crack + wet internal pop |
| 4. Sag | 0.30–0.72 s | Bottom flattens; top leans 6–10°; colour loses 25–35% saturation; face droops | Coast decelerates; camera holds horizon and moves another 4% closer | Goo strings from cracks, 3 heavy creaks, damp roll loop pitching down |
| 5. Chunk loss | 0.72–1.02 s | 3–5 large rind pieces peel away in travel direction; seeds visible inside | Camera look-ahead reduces so the shell stays central | Local non-colliding chunks, 12–20 seeds, two pulp splats, asymmetric `thok-thok` |
| 6. Burst | At 1.02 s; impulse 0.08–0.12 s | Shell expands to 1.08, compresses to 0.90, then ruptures | 0.05 s hit-stop, 0.18–0.28 s shake, max 1.2° rotation/0.35-stud translation; reduced-effects tier halves it | Orange/green goo ring, 24–36 seeds high tier or 10–14 reduced, 6–10 rind chunks, inner flash, bass `whump` + wet splat + seed rattle |
| 7. Reward reveal | 1.12–1.85 s | Debris clears center; reward icon/object rises from goo; amount ticks to exact server award | Camera stops shaking and gently pushes 6–8%; input remains locked until result is readable | Gold/candy arc pulls toward HUD, 0.55 s number tick, rarity sting; reward text appears 120–180 ms after burst, not simultaneously |
| 8. Return | 1.85–2.35 s | Reward banks; husk leaves one brief stain/seed decal then fades | Camera blends to plaza and restores avatar/control | Bank chime, UI counter punch, next-goal arrow; no unexplained teleport cut |

Normal playable rolling remains **10–14 seconds**; the terminal deterioration/reveal adds about **2.35 seconds**. The warning overlaps the final playable portion, so total loss of control is only about 1.9 seconds. On a first run, place no obstacle inside the last 2.0 seconds; the player should watch the new mechanic, not fail a reaction test during it.

### Technical art rules

- Use three authored shell meshes/material masks (`Healthy`, `Cracked`, `Collapsed`) plus detachable chunks. Do not fake the entire deterioration with a red tint and scale tween.
- Keep one stable collision sphere until control ends. Visible sag/chunks are cosmetic, so deformation never changes the authoritative lane hitbox mid-decision.
- The burst is a custom local VFX, not a damaging Roblox `Explosion`. Roblox's Explosion can break joints and apply force unless explicitly neutralized ([Explosion documentation](https://create.roblox.com/docs/reference/engine/classes/Explosion)); Pumpkin needs predictable cosmetic debris and no character deaths.
- Emit particles in directional groups: goo mostly radial/low, seeds radial/high with gravity, rind chunks forward-biased, reward particles inward toward the reveal. Roblox's particle guide recommends tuning size/speed/lifetime and randomizing ranges rather than making every particle identical ([ParticleEmitter tutorial](https://create.roblox.com/docs/tutorials/curriculums/artist/work-with-particle-emitters)).
- Suggested high-tier caps at the burst: 36 seeds, 10 chunks, 8 goo droplets, 2 decal splats, 1 ring, 1 flash, 1 temporary light. Reduced tier: 14 seeds, 5 chunks, 4 droplets, 1 splat, no temporary light.
- Use a four-layer sound stack: dry crack, wet pulp, low body impact, light seed rattle. Randomize only ±3% pitch on the signature burst so it remains recognizable. Roll/creak beds stop on the burst frame.
- Colour progression: healthy orange `#FF6B00`; crease `#8F2E0A`; warning interior `#D8FF49`; pulp `#9ECF2E`; final rind brown-orange around `#A94716`; reward yellow `#FFD400`. Fade the shell, never the reward.

### Games that demonstrate parts of this sequence

- **Break and Steal an Egg:** repeated hits/cracking lead to a hatch and object reveal—the closest reference for progressive surface damage and reward staging ([gameplay](https://www.youtube.com/watch?v=uT5R6PyMrQg)).
- **Steal An Egg:** carried egg → timed/offline hatch → persistent pet is the clearest transformation-to-retained-value reference ([beginner guide](https://steal-an-egg.robloxgamewiki.com/guide/beginner-guide/)).
- **Fish It!/Fisch:** active tension resolves into a held collectible with rarity/value; useful for delaying the readable reward until after the contact climax.
- **Ball Game:** its July 2026 description says shooting balls six times makes them explode and grant the maximum multiplier in a small radius, a direct precedent for countable buildup → burst → payoff ([dated game snapshot](https://fortnite-maps-stats.vercel.app/roblox/10277874067)).
- **+1 Stone Skipping:** each bounce is countable through repeated contact feedback; use that cadence for the warning cracks.
- **Mega Marble Run Pit / Ride a Box Down a Slide:** older rather than current-market references, but useful for contained third-person rolling, drops, funnels, collision comedy, and alternating enclosure ([Mega Marble course notes](https://roblox.fandom.com/wiki/Player:SeanMichaell/Mega_Marble_Run_Pit), [Ride a Box gameplay](https://www.youtube.com/watch?v=pm0uwYs2Nzw)).

## Ordered Codex build plan

Each task is deliberately bounded. Stop after each capture gate; do not build all systems and hope the final screenshot works.

1. **Reference-board task:** assemble current screenshots/frames for the eight fixed shots, the approved palette, and the one selected CC0 kit. Output only a target sheet and provenance manifest.
2. **Hero-pumpkin art task:** model/render Healthy, Cracked, Collapsed, chunks, seeds, goo membrane, stem, and rider window in Blender; enforce stable names/pivots and compare at game-camera distance.
3. **One-room visual prototype:** import only the pumpkin plus a small finish bowl into a daylight Studio test place; prove healthy → crack → sag → burst → reveal with no course or economy.
4. **Feel prototype:** add roll audio, crack cadence, custom local burst, exact effect caps, reward delay, camera impulse, and reduced-effects mode. Record the 2.35-second sequence at 60 fps.
5. **Rolling-physics slice:** build a 10–14-second three-lane spline with correct axle rotation, ground snap, banks, one hop, measured velocity, stable horizon, and local prediction.
6. **Course-art slice:** dress only one spawn-to-finish route using the approved kit plus custom landmarks; add two turns, tunnel, canyon, sky reveal, and burst bowl while preserving sight time.
7. **First-minute loop:** connect grow → latch → steer → deterioration → explode → exact bank → one next upgrade. Hide all non-core UI until the first reward lands.
8. **UI/mobile pass:** create fixed HUD slots, big speed/shell state/reward numbers, touch lane intent, gamepad graph, safe insets, and four-resolution captures.
9. **Economy/retention pass:** simulate 5/15/30 minutes, add one physically visible session goal and one return goal, then playtest the free path before configuring any offer.
10. **Performance/safety pass:** quarantine/audit assets, pool effects, apply distance relevance, run seeded fairness tests and the 10-minute baseline-phone soak.
11. **Gauntlet capture:** produce the eight fixed in-engine shots plus short unedited first-run video; judge against Steal An Egg (state clarity), Keyboard Escape (motion feedback), Fisch (hierarchy), and Egg (crack/reveal).
12. **Expansion only after green:** add remaining zones, pets, weekly novelty, and ethical live-price monetization only when the vertical slice has zero P1 “worse” scores.

## Bottom line

The market does not show that Pumpkin needs more panels, currencies, or generic props. It shows that one object must own the fantasy, change visibly, respond on every contact, and end in a reward staged clearly enough to remember. The decisive build is not a larger game; it is one excellent 12-second roll and one excellent 2.35-second death-and-reveal sequence.
