## Review limits and lessons

Least settled: **hub-perspective** (default-camera sightline needs Studio proof) and **panels** (dense small labels; Index image has an extra tile). Build the precise counts above. Owner phone review is still pending.

- When escape and progression share a lane, draw HOME direction first because the far gate otherwise reads as the escape goal.
- When using studded style, specify round hollow pumpkins separately because generation tends to cube every object.
- When generating mobile HUDs, require currency inside gameplay because asset margins can hide missing controls.
