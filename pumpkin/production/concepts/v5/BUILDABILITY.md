## Rendering contract and limits
Only Grass, Cobblestone, WoodPlanks, Brick, Slate, SmoothPlastic and Neon in the v5 world. Colours vary; new material variants, painted albedo and baked illumination do not. UI glyphs/text and particle sprites remain permissible Roblox image assets; they are not world-surface painted textures.

Limit codes are repeated in every screen table:
- **L — Lighting:** Future-style dynamic shadows/local lights; current Studio uses LightingStyle=Realistic, PrioritizeLightingQuality=true. Legacy Future only where that property still exists. Set in Studio Properties, not a gameplay script. Graphics/device settings can reduce shadows/effects. Neon is not a light source; pair focal emitters with a bounded PointLight. No assumed GI/ray-traced bounce.
- **A — Atmosphere:** one global distance-scattering treatment, not separate painted fog layers or cinematic DOF. It can soften the horizon, not invent geometry.
- **B — Bloom:** affects bright pixels, not a controllable painted rim on every asset. Small Neon accents only; never use whole-screen glow to hide geometry.
- **M — Mesh:** request MaxTriangles ~10,000 per generated mesh as the documented default/workflow cap; this is NOT asserted as the universal current importer hard limit. Target hero props 500–2,500 tris; static assemblies split by material/rig need, not to evade a budget. Generated topology/UVs/separable shells/rigs are not guaranteed; Blender cleanup required. MeshPart.RenderFidelity=Automatic; decorations noncolliding, CanTouch/CanQuery off where safe; simple collision hulls.
- **T — Textures/SurfaceAppearance:** SurfaceAppearance PBR maps are supported on UV MeshParts and depend on quality. Roblox CAN display hand-painted textures if uploaded; the forbidden effect here is the v4 view-dependent painted lighting/detail pretending to be 3D. v5 disallows such maps. Use native materials + actual facets; no SurfaceAppearance/TextureID on world assets for this pass. Normal maps cannot create silhouette, parallax or cloth movement.
- **P — Part/mobile budget:** no universal safe part cap. Proposed hub totals at end are project targets, not engine guarantees. Clone modular geometry, avoid one part per leaf/tile/straw strand, stream distant zones, profile a real baseline phone. Count descendants, transparent overdraw, lights and moving rigs as well as BaseParts.
- **E — Effects:** ParticleEmitter draws 2D sprites; documented max continuous rate is 400/s desktop, 100/s mobile per emitter, not a recommended use rate. Here use 6–12 particles per hit, <=8 reveal rays and <=12 chips; <=120 simultaneously live particles hub target. Rate=0 for bursts, lifetime 0.25–0.7s. LightEmission does not light surroundings. Real 3D chunks require pooled mesh/Part pieces. Trail/Beam are ribbons, not painted curved volumes.
- **U — UI:** ScreenGui Frames/UICorner/UIStroke/TextLabel/ImageLabel and ViewportFrame model portraits. BillboardGui attaches labels to actual interactables; set MaxDistance and avoid AlwaysOnTop on labels that would reveal occluded targets. Respect platform/device safe insets and readable touch sizes. No invented finished economy: balances, hit counts, boss percentage, slots and sample cost/unlock below are **illustrative concept states only**, not game facts.
- **R — Rigs:** real R6/R15 or custom Motor6D/bone rigs; screenshot pose requires authored animation and grip attachments. No cloth simulation or generated working rig assumed. Pup silhouette is custom authored; keep studs in one mesh, not hundreds of loose parts.
- **W — Water:** Terrain Water is valid Roblox, but outside the requested seven-material v5 whitelist. For v5 use shallow anchored SmoothPlastic coloured surfaces, chunky waterfall strips and sparse E droplets. No realistic fluid simulation, painted foam or mirror-perfect reflection. Collision is a separate invisible walkable bank/bridge plan, not a shader.

Documentation: [realistic lighting](https://create.roblox.com/docs/tutorials/use-case-tutorials/lighting/enhance-indoor-environments), [post processing](https://create.roblox.com/docs/environment/post-processing-effects), [materials](https://create.roblox.com/docs/parts/materials), [SurfaceAppearance](https://create.roblox.com/docs/reference/engine/classes/SurfaceAppearance), [particles](https://create.roblox.com/docs/effects/particle-emitters), [generation triangle controls](https://devforum.roblox.com/t/assistant-updates-mesh-generation-new-mcp-server-tools-screenshot-tool-and-more/4527258), [model generation](https://create.roblox.com/docs/parts/model-generation), [streaming](https://create.roblox.com/docs/workspace/streaming), [performance](https://create.roblox.com/docs/performance-optimization/improve).
