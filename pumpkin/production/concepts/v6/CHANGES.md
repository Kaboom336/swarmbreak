## Lessons

- When a reward image says nine, count visible models, because summary labels can hide missing results.
- When a tool must match across views, provide its card as a reference, because text alone drifts.
- When removing clutter, recheck each retry, because imagegen can reintroduce a competing landmark while fixing the foreground.
