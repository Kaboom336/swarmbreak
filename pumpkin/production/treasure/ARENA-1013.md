### Deadline and ownership contract

The owner's timer intent is ambiguous. **Default proposed interpretation: run before the portal's cargo window expires, not survive for60s before it opens.** This alone does not prove players keep running: moving between cover may be optimal. Guardian pursuit and the existing idle-carrier drop supply motion pressure; route playtests decide whether more is needed.

At first completed nest hold, server sets item `escapeDeadline = now + 60.0`. Pre-steal planning has no countdown. All same-arena occupants see that one item clock; a late join sees remaining time. No per-holder timer, refreshed shield, re-roll, geometry reset or second event clock. Portal remains open for empty hands at all times and carried treasure only while before deadline. Carry banner becomes “Escape · 0:SS”; amber at≤15s, red at≤5s, bounded enlarged final5s numerals without covering landing/disc.

Server boundary entry at `now < deadline` atomically locks SecurePending; `now >= deadline` loses. Same server clock resolves all ties, not a client's displayed countdown. Durable award acknowledgment, not timer entry, commits ownership. Once locked, deadline is suspended for reconciliation; definite no-write failure returns cargo to a legal danger socket with retry deadline **max(originalDeadline, rollbackNow + 10s)**, preserving same ID/roll and any longer original time. Only a server-verified definite failed write permits this retry adjustment; normal actions never refresh it. Ambiguous writes stay locked, no expiry/refill/rival award; reconcile same ID. This explicit storage-failure exception cannot be activated by normal drop/Grab. It adds no acknowledged escape before durability.

At expiry of Carried/Dropped cargo: clear holder/holds; dissolve that ID back toward nest visually, retire it without reward; reset guardian to patrol and remove all traps in that arena. New nest item appears after3s with a new ID and roll; clock starts only on its first Steal. Do not return expired ID to Nest and reroll it. Occupants remain; no damage, death, pet/Coins loss or forced teleport. Pending/secured cargo is unaffected. Disconnect/reset/outer fall still drops at a legal socket and preserves the deadline unless expired. Empty arena retires abandoned item without award. Existing10s idle +2s warning/drop stays.

Retain <30s fresh secured reward, <120s earner,20–45s uncontested trip and30–60s full-repeat targets; a60s deadline does not certify any of these. Record all eight novices and losers. If owner chooses mandatory60s survival, these timing targets must be rewritten explicitly and the design re-arenaed before implementation.
