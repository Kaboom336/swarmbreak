# Section craft lessons — S1

1. When starting a scene, render the exact arrival camera first, because the existing upright portal hid the entire scene despite looking acceptable from above. Keep the portal low enough to reveal the next decisions.
2. When a lawn looks flat, check the full supporting footprint and the route buffer before placing a cluster, because this map's visible turf conceals stepped voxel floors and curved walking surfaces. Move or shrink a bed instead of forcing it across a grade.
3. When detail disappears from the player frame, move the meaningful cluster into that frame before adding more props, because an attractive overview does not create a readable first impression. Use a low shoulder garden, warm timber and a watering barrel; preserve the central corridor and all route mouths.

## S1 round 2

1. When farm props disappear behind planting, move a recognizable barrel/cart forward and raise a shrub silhouette, because overview prop count does not establish the arrival story.
2. When dressing a route mouth, test the whole vertical prop against cliff solids as well as floor/lane contact, because supported mine-post feet can still leave the post buried in hill earth. Fit face trim when no thick-post pocket remains.
3. When sizing imported kits, measure actual mesh bounds, because a tall target envelope still produces a squat barrel when uniform fitting is capped by width. Use a checked fitted prop when the player-scale height must be exact.

## UI pass after S1

1. When a floating tag looks missing, inspect its parenting before changing fonts, because the tiered-pet branch returned before its TextLabel was attached.
2. When comparing UI against promo crops, label the evidence and render proxy explicitly, because a logo or thumbnail cannot prove a game's live font, mobile layout or billboard settings.
3. When UI spans screen panels and world labels, share type/outline/rarity tokens but size world tags in studs plus a small pixel floor, because fixed pixel tags do not recede naturally and unrestricted AlwaysOnTop creates clutter.

## S1 round 3

1. When a prop exists but fails to read, measure visible pixels in the exact arrival view, because object counts and overview shots conceal tiny or off-screen dressing. Use occlusion-aware tag masks and fixed corner regions.
2. When framing a wide corridor, move large silhouettes farther along its shoulders until they enter the camera frustum, because props close beside the camera can sit entirely outside the image.
3. When hanging vines, attach to the visible wall face and its actual vertical span, because a hill's cap slab can have empty space below it. Check contact before rendering.
