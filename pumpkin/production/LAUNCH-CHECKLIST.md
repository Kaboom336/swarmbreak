# Steal a Pumpkin: launch checklist (Zion's clicks, in order)

1. Studio: File > Save (Ctrl+S). Keeps the new hub, King and lanterns.
2. Turn on 2-Step Verification on your Roblox account (needed to publish).
3. Studio: File > Publish to Roblox > New game. Name "Steal a Pumpkin 🎃". Keep it Private for the test.
4. Game Settings > Security > turn ON "Enable Studio Access to API Services" (saving needs this).
5. Game Settings > Places > Max Players = 8.
6. Test with me: play the private game for 5 minutes, leave, rejoin. Your candy and pets must still be there.
7. Store page (creator dashboard > your game > Configure):
   - Title: Steal a Pumpkin 🎃
   - Description: (below)
   - Icon + 3 thumbnails: I make these in-game; you upload them.
8. Monetization (optional for day 1, ask me first): create the Game Passes and Developer Products listed in PatchConfig (Double Candy, VIP, candy packs), paste their IDs back to me, I wire them in. Badges: Welcome, First Steal, First Hatch (paste IDs).
9. Switch the game to Public.
