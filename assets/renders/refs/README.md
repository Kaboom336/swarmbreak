# Reference bar (open-licence stylized game models, rendered with our own studio setup)

These are NOT ours. They are here so every judge and artist compares Swarm Break models against real
stylized game assets in the same lighting. refs.json holds the measurements (triangles, flat-shaded fraction,
materials, size).

| Set | Licence | What it shows |
|---|---|---|
| Kenney Starter Kit FPS / 3D Platformer (KenneyNL on GitHub) | MIT / CC0 assets | blaster, blaster-repeater, enemy-flying, character, coin, wall, platform: chunky 200-700 tri models, 1 palette texture |
| KayKit Space Base Bits, KayKit Dungeon Remastered (Kay Lousberg) | CC0 | sci-fi base modules, cargo, lights, lander, drill; dungeon props: 100-1500 tris, 1 palette texture |
| Khronos glTF sample Fox (PixelMannen, CC BY 4.0) | CC BY 4.0, reference only | a 656-triangle animal that reads perfectly |
| three.js RobotExpressive (Tomas Laulhe, CC0) | CC0 | 3300-tri stylized character, 3 flat colors |
| Bevy alien (Kenney, CC0) | CC0 | 292-tri character, 5 flat colors |
| three.js PrimaryIonDrive (CC BY) | reference only | layered emissive sci-fi detail |

What they have in common (measured, refs.json): 100 to 1500 triangles per prop or character, one material,
flat saturated colors in big areas, exaggerated proportions (heads and hands), no small floating detail.
CC0 pieces may be kitbashed into our arena; CC BY pieces are for looking only.
